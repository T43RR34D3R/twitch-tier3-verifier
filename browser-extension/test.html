🚀 Installation Instructions:

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" in the top right corner
  3. Click "Load unpacked" button
  4. Select the browser-extension folder
  5. The extension should appear in your browser toolbar

🎮 How to Use:

  1. Configure: Click the extension icon and enter your server URL and channel name
  2. Visit Twitch: Go to any Twitch channel page
  3. Highlight Messages: Click on chat messages to highlight them
  4. See Results: Highlighted messages appear with golden styling

🔧 Server Requirements:

Make sure your backend server is running and has these endpoints:

POST /api/twitch/chat - Receive highlight/unhighlight actions
GET /api/highlights/{channel} - Fetch existing highlights
POST /api/highlights/{channel} - Add new highlight
DELETE /api/highlights/{channel}/{id} - Remove highlight
